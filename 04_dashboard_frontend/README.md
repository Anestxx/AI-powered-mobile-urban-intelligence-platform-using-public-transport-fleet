# CODYSSEY Frontend v1

Frontend-only command center prototype for the SIH CODYSSEY project.

Features: live city map, sensing fleet, road/infrastructure alerts, traffic intelligence, unsafe activity, emergency priority corridor, cross-bus corroboration, confidence/severity, event stream, city coverage, dark/light mode and responsive layout.

## Run
npm install
npm run dev

Open the Vite URL, normally http://localhost:5173

This version intentionally uses mock data. Next integration replaces mock data with FastAPI endpoints.
